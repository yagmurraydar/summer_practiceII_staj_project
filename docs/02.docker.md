# Docker Temelleri

## 1. Container ile VM Arasındaki Fark

Container ve Virtual Machine (VM) birbirinden farklı sanallaştırma yöntemleridir.

VM, kendi işletim sistemini ve kendi kernel'ini çalıştırır. Örneğin VirtualBox içinde Ubuntu çalıştırdığımızda, Ubuntu kendi kernel'i ile birlikte çalışır. Bu nedenle VM'ler container'lara göre daha fazla sistem kaynağı kullanır.

Container ise host işletim sisteminin kernel'ini paylaşır. Container'ın içinde ayrı bir kernel bulunmaz. Bunun yerine uygulama ve çalışması için gereken bağımlılıklar container'ın içinde bulunur.

Bu nedenle container'lar genellikle VM'lere göre daha hafif ve hızlıdır.

Kısaca:

```text
VM
Host
 └── Virtual Machine
      └── Kendi işletim sistemi
           └── Kendi kernel'i


Container
Host
 └── Docker
      ├── Container
      └── Container
           └── Host kernel'ini paylaşır



           Python'da venv, aynı sistem içerisindeki Python paketlerini birbirinden izole etmek için kullanılır.

Normal bir Linux ortamında farklı projelerin birbirlerinin Python paketlerini etkilemesini engellemek için .venv kullanabiliriz.

Ancak Docker container zaten uygulamayı host sistemden izole eder.
Host
│
├── Python projesi
│
└── Docker Container
     ├── Python
     ├── FastAPI
     ├── SQLAlchemy
     └── psycopg2 

     Container'ın kendi dosya sistemi ve Python ortamı olduğu için container içinde ayrıca venv oluşturmak çoğu durumda gereksizdir.

Bu nedenle Docker ile Python uygulaması çalıştırırken genellikle doğrudan container'ın Python ortamına gerekli paketleri yükleriz.

## 5. Volume Neden Gereklidir?

Container'ların dosya sistemi kalıcı depolama için güvenilir değildir.

Bir PostgreSQL container'ı silindiğinde container'ın içerisindeki veriler de kaybolabilir.

Örneğin PostgreSQL verilerini doğrudan container'ın kendi dosya sisteminde tutarsak:

```text
PostgreSQL Container
└── Database
    └── Tasks 
    Sonuç

Bugün Docker ile çalışırken temel olarak container'ların VM'lerden farklı olarak host kernel'ini paylaştığını, container içinde genellikle ayrıca Python venv kullanmaya gerek olmadığını ve port mapping sayesinde host ile container arasındaki bağlantının sağlandığını öğrendim.

Ayrıca Docker Compose içerisindeki container'ların birbirleriyle iletişim kurarken localhost yerine servis adlarını kullandığını öğrendim. PostgreSQL verilerinin container silinse bile korunabilmesi için Docker volume kullanılması gerektiğini gördüm.
